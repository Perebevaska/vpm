# Клиент WireTurn (WebDAV-профиль)

WireTurn — готовый Android-клиент, который умеет тот же протокол, что webdav-tunnel.
Ему нужно только скормить **client URI**, напечатанный сервером.

## Шаг 1. Установить WireTurn

- Скачай APK из релизов: `https://github.com/spkprsnts/WireTurn/releases`
  (последний стабильный, сборка **arm64-v8a**).
- Разреши установку из этого источника → установи.
- Не качай с левых зеркал — для VPN-клиента это риск подмены.

## Шаг 2. Завести WebDAV-профиль

Самый простой путь — импорт готового URI от сервера (в нём уже логин, пароль,
тюнинг и `enc=1`):

1. Скопируй `webdavs://...`-строку, которую напечатал сервер (шаг 3 в
   `SETUP-server-webdav-tunnel.md`).
2. В WireTurn → создать профиль → тип **WebDAV** → **импорт из буфера обмена**
   (или QR, если сгенеришь QR из этой строки).
3. Профиль подхватит URL `webdav.yandex.ru`, логин, пароль, шифрование и параметры.

Если вводишь вручную — поля должны совпасть с сервером:
- **URL:** `https://webdav.yandex.ru`
- **Логин:** твой Яндекс-логин
- **Пароль:** пароль приложения (тот же, что на сервере)
- **Шифрование (AES-256-GCM):** **включить** (обязательно совпадать с `-enc` сервера)
- Тюнинг (poll/chunk и пр.) — как в URI сервера.

## Шаг 3. Проверка

1. **Вне БС** (обычный Wi-Fi): включи профиль → открой в браузере `api.ipify.org`
   через WireTurn → должен показать IP выхода цепочки (`meat`), не твой домашний.
2. **В БС** (мобильный интернет, Wi-Fi выключен): тот же профиль → открой сайт.
   Работать будет медленно (КБ/с) — это норма для резерва.

## Важно

- **Шифрование и пароль обязаны совпадать** с сервером, иначе чанки не расшифруются.
- **Держи авторизацию локального прокси включённой** в WireTurn (РКН сканирует
  открытые прокси-порты — открытый порт без пароля может привести к блокировке IP).
- Один аккаунт Яндекса используют и телефон, и сервер — это нормально, они
  координируются через чанк-файлы в общей папке Диска.
- Это резервный канал: не гоняй через него видео/тяжёлый трафик, чтобы не плодить
  файловый churn и не ловить троттлинг Диска.
